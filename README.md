# 🛠️ Windows IT Maintenance & Diagnostic Tool

A PowerShell script designed for IT Support Technicians to automate routine desktop maintenance, clear temporary system cache, flush DNS settings, and quickly audit disk space and network status.

## 🚀 Features
* 🧹 **Temp Files Cleanup:** Cleans user and system temp folders to free up storage.
* 🌐 **Network Flush:** Clears DNS cache to resolve resolution issues.
* 💾 **Disk Audit:** Displays free vs. total space on local partitions.
* 📡 **Network Audit:** Lists active IPv4 addresses and network interfaces.

1. Open **PowerShell** as Administrator.
2. Run the script:
   ```powershell
   .\maintenance.ps1
